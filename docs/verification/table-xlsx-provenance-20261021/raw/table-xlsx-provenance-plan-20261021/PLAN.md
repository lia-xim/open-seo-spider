The matrix covers indexability, external nofollow, search evidence_complete, response body_complete/document_metadata_available, heading hidden_attribute, image eligibility, fragment target_complete, image body_complete, PDF text_complete/annotations_complete, extraction truncated and cookie httpOnly/secure.
